# Playtest 记录（5 人模板）

> 目的：把「我觉得手感不错」换成可复述的结论。每局 3–5 分钟，试玩后只问三个问题，
> 别引导、别解释机制，先让他自己玩。

## 统一三问

1. 跳跃跟不跟手？哪一下最别扭？
2. 射击跟不跟手？命中时有没有"打到了"的感觉？
3. 三选一词条看得懂吗？哪一局让你觉得变强了？
