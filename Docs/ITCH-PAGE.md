## 正文

### 这是什么

一个能做完整一局的小体量 roguelite 射击：**3 波敌人 + 1 个 Boss**，一局 3~5 分钟。

通关之后还有**无尽模式**：一波接一波，每 5 波一个 Boss，看你能撑到第几波。

每一波清场后从三张词条里选一张，你的 build 在第五分钟会明显和开局不一样——
可以走"高射速小弹丸"，也可以走"低射速大伤害"，还可以拿代价换体质。

### 两种玩法

| 模式 | 结构 | 终点 |
| --- | --- | --- |
| 标准 | 3 波，第 3 波是 Boss | 打赢 Boss = 通关 |
| 无尽 | 一波接一波，每 5 波一个 Boss | 没有终点，看能撑到第几波 |

### 一局的流程

1. 你在房间正中（或某块平台上）出生，敌人从两侧的墙后飞进来；
2. 边跑边跳边射，清完这一波；
3. 屏幕下方弹出三张卡，选一张（也可以按 1 / 2 / 3）；
4. 下一波：**平台布局重新随机**，出生点也换地方；
5. 标准模式第 3 波换成 Boss；无尽模式每 5 波一个，血量一个比一个厚；
6. 通关或阵亡，结算页会告诉你命中率、挨了多少下、最后一击来自谁。

### 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `A` / `D` |
| 跳跃 | `Space`（按住跳更高，松手会截断） |
| 射击 | `J` 或鼠标左键 |
| 选卡 | 鼠标点击，或 `1` / `2` / `3` |
| 暂停 / 设置 | `Esc` |
| 静音 | `M` |
| 标题页快速开局 | `空格`（标准）/ `E`（无尽） |

### 一些设计上的选择

- **平台能挡子弹**：悬浮平台不只是落脚点，还是掩体。躲到后面，射手和炮台就打不到你——
  "站在哪"本身成了一个决策。
- **敌人靠行为分化，不靠加血**：冲锋怪逼你跳，炮台逼你换位，射手逼你走位。
- **失败要能解释**：结算页不写"你死了"，写"命中率 62%，挨了 4 下，最后一击来自冲锋怪"。
- **地图真的每局不一样**：平台数量和位置每关重生成，同一 seed 可以完整复现。
- **没有一个美术资源**：所有图形和声音都是运行时生成的（纯色块 + 程序合成的循环 BGM）。
  所以包很小，加载很快。

### 已知问题

- 敌人没有寻路，冲锋怪是直线撞过来。
- Boss 只有两个招式（二阶段只是更快的同一套）。
- 音乐只有一段循环，不会跟着战斗强度变化。
- 键盘操作需要在画面内点击一次（浏览器要求用户交互后才能播放声音）。

### 反馈

如果你玩到了什么明显不对劲的地方（卡住、打不到、看不懂），欢迎留言说清楚**当时在第几波、在做什么**，
这类信息比"不好玩"有用得多。
